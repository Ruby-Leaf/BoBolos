# Como funcionam as pastas

Esse projeto possui algumas regras de pastas que precisam ser atentadas

* Objetos => São separados por  cena e categorias para deixar o projeto visualmente mais eficiente
* Scripts => Devem ser separados entre Services e Globais
  * Services => Todos os arquivos de funções e que realizem alguma ação
  * Globais => Todas as variaveis globais do projeto, Enums e Structs
* Sprites =>  São separados por  cena e categorias para deixar o projeto visualmente mais eficiente
